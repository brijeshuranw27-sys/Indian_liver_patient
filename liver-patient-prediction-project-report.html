Liver patient prediction

This prototype turns a small set of liver laboratory measurements into a transparent classification workflow for exploration and learning.

Approach

The pipeline selects nine numeric laboratory features, imputes missing values with medians, and trains a class-balanced random forest. Flask exposes the trained pipeline through a JSON endpoint and a responsive browser form.

Dataset

The bundled CSV is a compact example dataset with a binary target: class 1 represents the positive liver-disease class in the source convention, while class 2 is normalized to 0 during training.

Limitations

This example is not a clinical tool. It has a tiny demonstration dataset, no external validation, and no patient safety review. Outputs must not be used for diagnosis or treatment.

Reproduction

Install the packages in requirements.txt, run python train_model.py, and start python app.py.
